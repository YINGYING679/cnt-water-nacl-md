# Surface-normalized ion deficit length (300–500 ns)

For each ion species,

$$K_i=\frac{C_i^{CNT}}{C_i^{bulk}},\qquad i=\mathrm{Na^+,Cl^-}.$$

Defining the integrated concentration deficit per cylindrical wall area gives

$$K_i=1-\frac{S}{V}\delta_{\Theta,i}
     =1-\frac{2\delta_{\Theta,i}}{R},$$

and therefore

$$\delta_{\Theta,i}(R)=\frac{R}{2}(1-K_i).$$

Treating $R$ as exact,

$$\mathrm{SEM}_{\delta_{\Theta,i}}
  =\frac{R}{2}\mathrm{SEM}_{K_i}.$$

For $K_i=0$, the plotted value is $R/2$. This is a surface-normalized total
deficit and does not mean that a sharp layer of thickness $R/2$ was directly
observed. Zero-occupancy and intermittent-occupancy flags are retained in the
data tables. The older equivalent sharp-annulus results remain separate.

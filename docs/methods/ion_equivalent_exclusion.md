# Equivalent ion exclusion length (300–500 ns)

For each ion species, using the central 4.0 nm CNT region and its species-specific remote-reservoir reference:

$$K_i = \frac{C_i^{CNT}}{C_i^{bulk}}, \qquad i=\mathrm{Na^+,Cl^-}.$$

The equivalent sharp cylindrical exclusion-layer mapping is

$$K_i=\left(1-\frac{\delta_{\mathrm{ex},i}}{R}\right)^2,$$

so

$$\delta_{\mathrm{ex},i}=R(1-\sqrt{K_i}).$$

For $K_i>0$, treating $R$ as exact, SEM propagation is

$$\mathrm{SEM}_{\delta}=\frac{R\,\mathrm{SEM}_{K_i}}{2\sqrt{K_i}}.$$

At $K_i=0$, $\delta_{\mathrm{ex},i}=R$ records that no ions were observed during the analysed interval; derivative-based SEM is undefined. This length is an equivalent partition metric, not a directly observed empty annulus next to the wall. Means and SEMs of $K_i$ come from four contiguous 50 ns blocks.
